# Playbooks

One section per askType (kebab-case label). Reuse an existing label before coining a new one.
Each section: what the ask looks like, what to check before drafting, questions usually needed,
and the draft shape that gets sent without edits.

## Filters

Patterns that are not asks for the user (learned from `fyi` / `not mine` replies). Matching items
are created as `filtered` and only appear in the digest.
